# FocusFlow

A lightweight, offline-friendly task planner. Add tasks with priorities, keep quick notes, and filter your day without logging into anything.

## Features
- Create tasks with priority, due date, and notes
- Inline filters for status, priority, and search
- Quick stats for total tasks and completion rate
- Sample data loader and one-click clear to reset your workspace
- Data stored locally in your browser

## Running the app
Use any static file server to open `index.html`. Two quick options:

```bash
# Option 1: built-in Python server
python -m http.server 8000
# Option 2: use serve if you have npm
npx serve .
```

Then visit `http://localhost:8000` in your browser.
